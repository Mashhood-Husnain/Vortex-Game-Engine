# Keyboard Shortcuts & Controls

All bindings below apply to **Editor Mode** unless noted otherwise.

**Jump to:** [Camera](#camera) · [Object Manipulation](#object-manipulation) · [Panels & Windows](#panels--windows) · [Project & History](#project--history) · [Play Mode & General](#play-mode--general)

---

## Camera

| Key | Action |
| --- | --- |
| **W, A, S, D** | Move camera horizontally |
| **Q, E** | Move camera up / down |
| **LEFT SHIFT + X** | Snap camera to X-axis view |
| **LEFT SHIFT + Y** | Snap camera to Y-axis view |
| **LEFT SHIFT + Z** | Snap camera to Z-axis view |
| **LEFT CTRL + X** | Toggle Camera Info |
| **Mouse Scroll** | Dolly Zoom In / Out|


## Object Manipulation

| Key | Action |
| --- | --- |
| **R** | Toggle Rotate mode |
| **T** | Toggle Translate mode |
| **Y** | Toggle Scale mode |
| **LEFT CTRL + L** | Use Local object transformations |
| **LEFT CTRL + G** | Use Global object transformations |
| **LEFT CTRL + Mouse Drag** | Snap selected model to grid |
| **RIGHT ALT** | Snap selected model to the ground |
| **LEFT CTRL + D** | Duplicate selected model(s) |
| **DEL** | Delete selected model(s) |

## Panels & Windows

| Key | Action |
| --- | --- |
| **LEFT CTRL + A** | Toggle Asset Browser |
| **LEFT CTRL + F** | Toggle File Viewer |
| **LEFT CTRL + B** | Toggle Image Viewer |
| **LEFT CTRL + P** | Toggle Engine Terminal |
| **LEFT CTRL + I** | Toggle Scene Inspector |
| **LEFT CTRL + W** | Toggle Creator Window |
| **LEFT CTRL + E** | Toggle Engine Stats |
| **LEFT CTRL + O** | Toggle Skybox / Post-Process Options |
| **LEFT CTRL + H** | Toggle Action Stack History |
| **LEFT CTRL + SHIFT + S** | Toggle Scene View |
| **LEFT CTRL + SHIFT + R** | Toggle Render View |
| **LEFT CTRL + SHIFT + I** | Toggle Engine Settings Window |
| **Right Mouse Click (on folder)** | Open folder options |

## Project & History

| Key | Action |
| --- | --- |
| **LEFT CTRL + S** | Save the current project |
| **LEFT CTRL + SHIFT + O** | Open existing project in Project Hub |
| **LEFT CTRL + SHIFT + N** | Open new project in Project Hub |
| **LEFT CTRL + Z** | Undo changes |
| **LEFT CTRL + Y** | Redo changes |
| **LEFT CTRL + C** | Compile scripts |

## Play Mode & General

| Key | Action |
| --- | --- |
| **LEFT CTRL + R** | Enter Play Mode |
| **TAB** | Toggle Engine Stats (**Play Mode only**; in the editor use `LEFT CTRL + E`) |
| **Escape** | Exit Play Mode (if playing) **or** exit the engine (if in editor) |
| **M** | Release / capture mouse (use this to interact with the Creator Tool or Inspector) |
| **Z** | Toggle wireframe view for all models |
| **F** | Toggle Fullscreen / Windowed mode |
