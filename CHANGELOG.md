# Changelog

All notable changes to **VortexEngine** are documented in this file.

## A note on the past and the future

**What happened:** Development on this project went quiet for roughly 4 months. During that time the project sat untouched while I was busy with other things (life). There is no detailed changelog for everything that was built before this point. The first entry below summarizes the state of the engine as it was when I came back and declared feature-complete enough for a first release.

**What happens from now on:** The project is now considered officially released (not really confident about it but "it is what it is" :)). Every change (if I get the time) to the engine will be accompanied by a version bump and a matching entry in this file. Each release will list what was added, changed, fixed, or removed, so it is always clear what differs between versions.

### Versioning Policy

- **MAJOR** (`X.0.0`): breaking changes to the engine's API or behaviour.
- **MINOR** (`0.X.0`): new features that don't break existing usage.
- **PATCH** (`0.0.X`): bug fixes and small improvements.

## Known issues and disclaimers

- **Bugs:** The engine has a lot of bugs. I'm aware of them and I'm working on them.
- **Platforms:** It should work on both Windows and Linux (should :)).
- **Code quality:** Some of the code is spaghetti (especially the GUI). Please do not look, I'm ashamed as a programmer :).
